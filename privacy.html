ツールの説明プライバシーポリシー利用規約

プライバシーポリシー

本ポリシーは、個人用バックアップツール「Creative Backup 96」に適用します。

扱うデータと目的

管理者本人が保存対象に指定した制作資料とそのファイル名・属性を、バックアップおよび復元のために扱います。Google Drive上では、設定したバックアップ先の暗号化データと、処理に必要な容量・ファイル情報を扱います。

認証情報と保管場所

Googleの認証情報は本人のMacのアクセスを制限した設定ファイルに保存します。バックアップの暗号鍵はMacのKeychainと本人が別途保管する回復用の控えで管理します。認証情報と鍵は、このサイトやバックアップの公開資料に掲載しません。

制作資料は暗号化して本人のGoogle Driveへ保存します。保存日時・結果・ファイル数などの実行記録は本人のMacに保存します。

第三者への提供

バックアップの保存サービスとしてGoogle Driveを使用します。Googleユーザーデータを広告、販売、他者の利用、または汎用AIモデルの学習のために提供しません。Googleユーザーデータの利用は、バックアップ・復元の目的と、Google API Services User Data PolicyのLimited Use要件に従います。

保存期間と削除

保存したバックアップは管理者本人が削除するまで保持します。世代の自動削除は有効にしていません。今後、保存期間や削除方式を変更する場合は、本ポリシーを更新します。Googleアカウントの設定からアクセス許可を取り消すと、その認証による新しい保存は停止します。許可を取り消すだけでは、既に保管したバックアップは削除されません。

この説明サイト

本サイトは閲覧用の静的ページです。フォーム、Google認証、アクセス解析、広告は設けていません。公開に利用するサービスが、配信や安全管理のためにアクセス記録を処理する場合があります。

管理と連絡

本ツールの管理者は唯一の利用者本人です。Googleの認証画面に管理者のサポート連絡先を表示します。
